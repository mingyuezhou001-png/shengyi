# 声译

面向手机浏览器的中英文实时翻译网页。支持中文→英文、英文→中文、连续语音识别、临时识别文本、译文自动朗读、手动输入翻译和本轮记录清空。

## 使用

1. 启动后使用 Safari 打开页面，允许麦克风权限。
2. 选择翻译方向，点击“开始同传”。
3. 如果浏览器不支持语音识别，使用“手动输入”。
4. 在 Safari 的分享菜单中选择“添加到主屏幕”，可获得接近 App 的入口。

## 开发

```bash
npm install
npm run dev
```

生产构建与运行：

```bash
npm run build
npm start
```

## 实现与限制

- React + TypeScript 前端，Hono + tRPC 后端。
- 语音识别使用浏览器 Speech Recognition 能力，朗读使用 Speech Synthesis；可用性取决于设备、iOS 与浏览器版本，并需要联网。
- 翻译通过服务端 AI SDK 调用平台模型，不在浏览器中暴露密钥。模型由运行时模型清单决定。
- 不保存录音，不持久化翻译历史；刷新页面会清空记录。
- AI 翻译可能消耗站点所有者额度。错误状态提供人工重试，不自动重复调用付费翻译。
